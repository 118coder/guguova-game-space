# NIGHT FLIGHT · 夜航 —— 设计规范

> 主题 id：`nightflight` · 版本 1.0.1
> 开屏 `nightflight（离港）` · 进游戏 `nfLaunch（跑道加速）` · 切换 `分瓣翻牌`

## 1. 一句话

**把启动器做成一张夜间航班的登机牌，放在离港大厅的航班表前。**

## 2. 构图

- **背景**：深夜蓝 `#04070d → #07101c`，叠经纬网、星点、虚线航路与远处地平线。
- **主视觉**：米白登机牌。左缘 34px 荧光黄绿色带，竖排 `NIGHT FLIGHT · 夜航 · GUGUOVA AIR`；
  牌面 67.4% 处是虚线撕口与上下两个票根缺口；右侧是圆形舷窗（9px 米白窗框 + 墨色内圈），
  窗内是 `--nova-hero`；右下角是条码；右缘竖排 `BOARDING PASS · 登机牌 · NO.001`。
- **文字列**：左 67%，眉标是等宽航班状态行，标题黑色 700，下面是荧光短线、属性行、
  荧光主按钮 + 墨线次按钮、跑道式时长条。
- **底带**：`DEPARTURES` 航班表。每张票根顶部 3px 荧光条，编号 `NF 01`，下方名称与时长。
- **游戏库**：与其它主题一致的 4 列 16:9 卡片网格（窗口高度 ≤700px 时收为 2 列）；每张卡片是登机牌票根（`NF 01` 角标 + 荧光顶条），列表末尾 `END OF MANIFEST`。
- **外观 / 设置**：深色控制台 + 等宽标签 + 荧光选中；主按钮为荧光平涂硬影。

## 4. 字体

- 标题：思源黑体 Medium 700，字距 `-.035em`，行高 1.02。
- 标签 / 时间 / 编号 / 条码注释：Cascadia Mono / Consolas，字距 `.1em`–`.24em`。
- 正文：思源黑体 Medium。
- 登机牌上的正文用墨色；牌外的正文用米白 / 次灰，不用纯白满屏。

## 5. 控件

- 主按钮：荧光 `#d9ff45` 平涂，1px 墨边，4px 硬偏移墨影，墨色字；悬停再偏移 1px，按下归位。
- 次按钮（牌面）：透明，1px 墨边，墨色字；悬停墨底荧光字。
- 次按钮（深色面板）：透明，1px `#2f5474`，米白字；悬停荧光边。
- 导航：等宽编号 + 中文；选中荧光字 + 2px 底线。
- 开关：方角，开=荧光，滑片为墨色方块。
- 选中：荧光 1px 边 + 外晕；不使用圆角药丸。

## 6. 动画

- **开屏**：`.intro-nf`。星图亮起 → 荧光地平线拉开 → 跑道中线加速 → `NIGHT / FLIGHT`
  分瓣字逐字翻下 → 航班行 + 真实日期 / 时钟 / 游戏数 → `BOARDING`。
- **进游戏**：`nfLaunch`。中心方形缝隙张开到全屏，从暗到亮。
- **切换**：`[data-variant="nightflight"]`。登机口关闭：上下深夜蓝面板合拢，中间展开一条
  奶油登机牌带（2px 荧光上下轨、两端圆缺口），荧光扫描条扫过一次，主题名以翻牌方式落在
  荧光色块上；`CURTAIN_HOLD = 560`。无模糊，只动 transform/opacity。

## 7. 禁忌

- 不伪造航班动态 / 在线人数 / 下载速度；`NF 001 / GATE 01` 只作为主题装饰编号。
- 荧光只做填充，不做大面积正文色；牌面正文一律墨色。
- 不使用圆角大卡片、玻璃模糊、柔光；舷窗是唯一的圆形。
- 条码与条码背景不得压住文字列。


## 8. 音效

16 个 cue 由 genny 合成：翻牌/木鱼（click/nav）、机场双音铃（select/confirm/chime）、
风与扫描（launchFall/exit）、PA 人声「boarding」（boot/launch）。
`tools/sfx-specs/themes-2.2-genny.json` + `make-themes-2.2.py`；全部 mono/44.1k/OGG，峰值 -1dB。

## 9. 禁止模糊

`appearance-bg`、`detail-art::before`、`launch-bg` 全部禁用；所有 `backdrop-filter` 置 none；
外观预览底为夜空实色 + 噪点，不使用模糊底图。
