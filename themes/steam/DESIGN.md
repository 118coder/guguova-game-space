# STEAM CLASSIC · Steam 经典 —— 设计规范

> **状态：未通过。** 1.8.0 交付后用户判定「太丑」，问题在构图与层次，不在配色。
> 返工方案、问题清单与验收标准见 `docs/HANDOFF-NEXT.md` §4–§7。
> 本文件保留作为**目标语言**的说明；落地效果以下一轮重做为准。

> 一句话：**把启动器做成桌面上开着的经典客户端窗口**——深蓝外壳、绿色主按钮、
> 蓝色链接、密集小字和一条库列表。
>
> 参考：Valve Steam 桌面客户端在 2010 年代形成的视觉体系（**不是** Big Picture，
> 也不是现在的 Steam Deck UI）。本文只提炼语言，不使用 Valve 的 Logo、图标或任何截图素材。

---

## 1. 为什么是「客户端窗口」

玩家对 Steam 的记忆不是一张海报，而是一个**窗口**：顶上一条深色标题栏，
左边是库，中间是当前游戏的头图，右边是状态，底下一条绿色的「开始游戏」。
这套主题直接把这个结构搬进启动器：

- 主视觉不是满幅照片，也不是一张纸，而是**一个有边框、有标题栏的窗口**；
- 窗口里唯一的图片是当前游戏的 16:9 头图，横在顶部；
- 所有信息按客户端的密度排：10–12px、1px 分隔线、大写微标签；
- 底部的游戏条就是「库列表」，选中项一条蓝线。

| 弱化 `--st-dim` | `#66727d` | 微标签、路径 |

## 3. 字体与排版

- 全篇思源黑体 Medium，标题 700，正文 400/500；**不用宋体**；
- 微标签 9–10px，全大写，字距 `.18em`–`.28em`；
- 数字用 `tabular-nums`（时长、计数、百分比）；
- 行高紧：正文 1.6–1.7，窗口内信息行 1.4；
- 主标题 `clamp(30–58px)`；长名自动降到 `clamp(22–38px)` 并允许两行。

## 4. 构图

```
┌ 标题栏  库 · 本机游戏 · 离线模式 ─────────────────────┐
│ ┌──────────────────────────────────────────────────┐ │
│ │ 16:9 头图（通栏，底部压暗）                        │ │
│ └──────────────────────────────────────────────────┘ │
│ 眉标 · 上次游玩               ┌ 库快捷入口 ────────┐  │
│ 游戏名（白色粗体）             │ 数量 / 状态 / 进度 │  │
│ 一句话 / 属性 / 按钮 / 进度    └────────────────────┘  │
└──────────────────────────────────────────────────────┘
```

- 窗口 `min(1120px, 82vw)`，1px `#2a475e` 边框，3px 圆角，深色投影；
- 标题栏 36px，左侧一行大写状态文案（真实文案：库 / 本机游戏 / 离线模式）；
- 头图通栏，高度 `clamp(150px, 21vh, 226px)`，底部 40% 渐变压暗，保证文字不压图；
- 右栏只在 `>1180px` 显示；窄窗收成单列并隐藏右栏，头图降到 130–180px；
- 矮窗（≤760px 高）再压缩：标题栏 32px、头图 118px、按钮 38px。

## 5. 控件

| 控件 | 做法 |
|---|---|
| 主按钮 | `#8ed629 → #5c7e10` 纵向渐变，1px `#4c6b22`，白字，2px 圆角，内高光 + 1px 外阴影 |
| 次按钮 | 半透明蓝底 + 1px 蓝边 + 蓝字，悬停提亮 |
| 开关 | 方角 2px，开=深蓝底 + 蓝色滑块 |
| 输入框 | `#0e141b` 底 + 1px `#38546b` + 内阴影，聚焦转蓝边 |
| 选中态 | 蓝色 1px 边 + 1px 内嵌线；列表项用左侧/底部蓝条 |
| 标签/徽章 | 1px 描边方框，9px 大写 |
| 卡片 | 面板色 + 1px 描边，悬停只换底色与描边 |

## 6. 三套动画

### 6.1 开屏「客户端启动」（`intro: steam`，2500ms）

| 时间 | 动作 |
|---|---|
| 0–520ms | 窗口从下方 16px 升起并淡入 |
| 120–540ms | 品牌字 `GUGUOVA` 淡入 |
| 240–1490ms | 进度条 0 → 100%（蓝色渐变） |
| 300 / 780 / 1260ms | 三个真实步骤依次点亮：读取本机库 → 检查封面缓存 → 准备界面 |
| 1750ms | 状态切成「库已就绪」，三个方块变绿 |
| 全程 | 计数与日期/时刻来自真实数据（`scramble` + `runMeter`） |

### 6.2 进游戏「窗口最大化」（`stMax`，460ms）

画面从 94% 放大到 100%，同时从暗部回到正常亮度，像窗口被双击最大化；不弹跳、不模糊。

### 6.3 切换幕布「客户端窗口推开」（440ms）

- 左侧 26.5% 的「侧栏」从左滑入，右侧 74% 的「主面板」从右滑入；
- 接缝是一条竖蓝线，主面板上方有一小段绿色标签条；
- 揭开时两侧沿原路退出，全程只动 `transform` / `opacity`。

## 7. 声音

材质：塑料键、滚轮格、低沉的硬盘嗡鸣、短数字提示音；只有 `switch` 用低通风声。

| cue | 材料 | 时长 |
|---|---|---|
| bong | 110Hz 低频 + 440Hz 提示 | 0.60s |
| click | 塑料键 1.7kHz | 0.09s |
| nav | 滚轮两格 | 0.08s |
| soft | 轻键 + 气声 | 0.10s |
| select | 1046Hz 提示 | 0.20s |
| confirm | 784 → 1046Hz | 0.50s |
| error | 146Hz 闷响 + 暗噪声 | 0.45s |
| tick | 2.1kHz 轻键 | 0.05s |
| chime | 880/1174/1568Hz | 1.16s |
| deep | 62Hz 嗡鸣 | 1.00s |
| launchRise / launchFall | 低频 + 上/下行 | 0.80 / 0.70s |
| switch | 低通风声 + 196Hz | 0.45s |
| launch | 低频 clunk + 104Hz | 0.85s |
| exit | clunk + 气声 | 0.50s |
| boot | 气声 → 嗡鸣 → 三音上行 → 确认 | 1.92s |

生成：`tools/sfx-specs/make-steam-sfx.py` → `ffmpeg -c:a libvorbis -q:a 5 -ac 1`。

## 8. 禁忌

1. 不要用 Steam 的 Logo、商店图、成就图标或任何官方素材；
2. 不要做大圆角、玻璃模糊、毛玻璃卡片——这是 2010 年代的客户端，不是现代网页；
3. 不要用绿色写正文，绿色只给主按钮与「就绪」；
4. 不要用红色做提醒，红色只给「程序缺失 / 删除」；
5. 不要给面板加七彩渐变或霓虹描边；
6. 不要伪造数据（在线人数、下载速度、成就数）；
7. 不要把纸纹、羊皮纸、金属浮雕带进来——那是别的主题的语言；
8. 切换动画里只允许深蓝、蓝与一条绿标签。

## 9. 验收

```bash
node tools/export-all.js --themes=steam --views=all \
  --sizes=1439x1124,960x600 --stress
```

- 30 字长名两行显示，不遮住头图与右栏；
- 960×600 下右栏隐藏、头图缩短，不出现纵向滚动；
- 所有文字在 `#1b2838` 上对比度 ≥ 4.5:1（正文 `#c6d4df` 约 9.8:1）；
- `reduce-motion` 与 `safe` 档不播放关键帧动画。
