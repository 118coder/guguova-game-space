# NOVA 正式启动器 · 功能补齐表

> 目标：从“主题展示型启动器”升级为**离线单机启动器**。
> 原则：不联网、不登录、不上传；所有记录可随数据包迁移到另一台电脑继续使用。

---

## 1. 已有能力（保留，不重做）

| 模块 | 已有功能 |
|---|---|
| 游戏接入 | Steam 库扫描（多库目录）、开始菜单 exe、`nova-game.json` 清单、手动添加 exe |
| 启动 | 真实进程启动、参数 / 工作目录、进程退出检测、崩溃判定、运行中管理 |
| 记录 | 累计时长、最近游玩、启动次数、收藏 |
| 媒体 | 16:9 主视觉、封面裁切、从 exe 图标生成、配色采样、构图调整 |
| 游戏库 | 搜索、最近/收藏/Steam 筛选、详情、编辑、移除、重新定位（编辑 exe） |
| 桌面体验 | 托盘常驻、真全屏、睡眠模式、手柄导航、键盘快捷键、沉稳/减少动效 |
| 主题 | 11 套主题、概念板预览、主题切换幕布、每主题开屏/进游戏动画 |
| 数据 | `%LOCALAPPDATA%\NOVA Game Space` 本地存储、损坏文件备份、日志 |

## 4. 数据包格式（`.nova-pack`）

```
NOVA-YYYYMMDD-HHmm.nova-pack   (zip)
├─ manifest.json
│   { schema: 1, app: "NOVA Game Space", version: "1.5.0",
│     exportedUtc, gameCount, mediaCount }
├─ library.json                完整 LibraryFile（游戏、设置、游玩会话）
└─ media/
   └─ <gameId>/hero.jpg, cover.jpg, logo.png …
```

导入规则：

1. 先备份当前 `library.json` 为 `library.json.before-import-<stamp>.json`。
2. 校验 `manifest.schema` 与 `library.json`。
3. `replace`：用包内库替换本机库；`merge`：按 `steamAppId` → `exePath` → `name` 去重合并。
4. `media/<id>/` 复制到本机 `media/<id>/`，把 `heroPath/coverPath` 重写为本机绝对路径。
5. 游戏 exe 路径不存在时保留记录，界面标“程序缺失”，用户可在“编辑游戏”里重新指定。
6. 导入完成后重载界面。

## 6. 离线原则

- 启动、计时、封面、统计、备份全部本地完成。
- 不请求任何网络接口；主题预览使用本地概念板。
- 数据包由用户自行复制到另一台电脑导入。
- Steam 库只读取本机 `appmanifest_*.acf` 与缓存封面；不访问 Steam 网络。
