# RIOT · 舞台残响 · 设计规范与设计理念

> 一句话：**白纸专辑封套**——一张灰白卡纸，右缘裁掉半张黑胶，灰墨泼溅，
> 一道朱红毛笔螺旋横扫标题，Saira 900 宽体重黑当主字。
>
> 参考：`新主题1/少女乐队呐喊.png`（另见 `游戏启动器-少女乐队呐喊.png`）。
> `assets/{splatter,spiral}.svg` 为本项目几何绘制；`Saira` 是 OFL 字体，许可随附。

---

## 1. 设计理念（为什么长这样）

原型是**实体唱片封套（album sleeve）**，不是"朋克配色 UI"。由此推出三条硬规则：

1. **封套上没有装饰横条。** 参考图的顶边是干净的卡纸切边，
   **没有任何条纹栏**。所以 `body::after`（其他主题用来铺顶带的那层）
   在这套主题里被压成 `height: 0; background: none`，顶栏只留一条
   `1px rgba(17,17,17,.55)` 的细黑线当"印刷裁切线"。
   ——**不要给它补顶带**（这是"参考图没有的东西不要自己加"的典型）。
2. **红是信号，不是底色。** 参考图里红只出现在笔触、胶带、小方块上，
   面积很小但极抢眼。所以 `--accent #e2001a` 永远配 `box-shadow: N px N px 0`
   的**硬投影**用法，绝不铺大面积；配色表里 red 的目标就只有 ≈10%。
3. **黑只给字用。** 曾经把活动条做成整块黑，black 占比直接超标（参考 ≈9%）。
   现在活动条回到纸底 + 2px 黑框 + 6px 朱红硬投影，黑只留在
   标题的 `text-shadow: 3px 3px 0 #111` 与文字本身。

## 2. 视觉语言 → 实现映射

| 参考图里的语言 | 落地位置 | 关键值 |
|---|---|---|
| 灰卡纸（不是象牙白！） | `--t-paper` 系列 + `.scene` | 外围场 `#aeaca7`（L .678 → 计量表判 light-grey）、主视觉板 `#e1ded6`（L .859 → paper，字压在这里） |
| 右缘裁切的黑胶 | `.hero-inner::after` | `right:-186px; 318×318; opacity:.92`（故意出血，靠 `probe-graphics.js` 确认不压字） |
| 灰墨泼溅 + 网点 + 斜纹 | **`.atmosphere`**（不是 `body::before`） | 网点 `radial-gradient` + `splatter.svg`；`.scene z0 < .atmosphere z1 < .stage z4`，`body::before` 会被 `.scene` 盖住 |
| 朱红毛笔螺旋 | `.hero-inner::before` 的第二层 | `background-size: 52% auto`，位置 `14% -30%` |
| Saira 900 宽体重黑标题 | `features.type = ink` + `themes/riot/assets/Saira.ttf` | `text-shadow: 3px 3px 0 #111` |
| 灰卡片分隔（纸不要一整块） | `.tile-art` / `.lib-art` / `.progress-track` / `.theme-card` / `.dock` | `#b0ada6` / `#a5a29c` / `#b8b5ae` / `#9f9c96` |
| 场景插画必须是**全灰** | `.scene > img` | `grayscale(1) contrast(.72) brightness(1.56)`——灰度 .85 会漏出 4.7pp 的"橙/绿" |
| 开屏 | `theme.json: "intro": "ember"` | 共用 astrolabe 骨架，红/黑配色（**待换成唱片出套**，见第 5 节） |

`features.texture = paper`（框架层的纸纹通道）、`type = ink`（油墨字体图层）、
`panel` 不启用。

## 3. 量化验收（v1.3.7 版，已收敛）

`python tools/measure-ratio.py --all`（参考图整图 vs 实机左侧 66% × 垂直 9%–72%）：

| 桶 | 参考 | 我们（起点） | 我们（现在） | 差 |
|---|---|---|---|---|
| paper | 49.8% | 77.3% | **51.0%** | +1.2 |
| light-grey | 13.2% | 2.0% | **13.5%** | +0.3 |
| red | 9.8% | 8.5% | **9.2%** | −0.6 |
| black | 9.0% | 5.2% | **8.3%** | −0.6 |
| mid-grey | 8.5% | 1.6% | **7.6%** | −0.9 |
| dark-grey | 7.7% | 3.1% | **10.2%** | +2.4 |

> **为什么之前几轮都收不动**：早期几版挑的"灰"全部**卡在计量表的纸色阈值上方**
> （paper 的判定是 `L > .72` 且 `chroma < .20` 且 `hue < 70`）：
> 外围场 `#cfcdc6` L .794、dock `#c4c2bb` L .751、卡片 `#d6d4ce` L .824、
> 进度轨 `#cfcdc7` L .796、主题卡 `#dedcd6` L .855、**主视觉板 `#eeece6` L .918**
> ——肉眼是灰，表里全是纸。第二个叠加错误：`.atmosphere`（唯一真正可见的整屏层）
> 当时铺的是一层**白色纱**（`rgba(255,255,255,.9→.96)` + 横向 96% 白），
> 把整张纸又洗白了一遍。
> 所以修法是：**把该是灰的都压到 L ≤ .70**，主视觉板保持纸色（标题压在上面，
> 铁律 1），网点/泼溅搬到 `.atmosphere`；再把 `.scene > img` 的 `grayscale(.85)`
> 改成 1.0（那 15% 残留饱和度就是"橙 2.3 / 绿 2.4"的来源）。
> 剩下的 dark-grey +2.4 是场景插画自己的暗部，不再追。

## 4. 不可回退的坑

1. **不要加顶带/顶栏条纹**（第 1 节第 1 条）。
2. **黑胶是"右缘裁切"而不是"放得下"**：`right:-186px` 是刻意的，
   让黑胶只露一条边。`audit()` 会把 `#content` 的横向 194px 记为
   `deco-bleed`（提示级），**这不是 bug**，用 `probe-graphics.js` 确认不压字即可。
3. **活动条不许整块黑**（黑占比会翻倍），纸底 + 黑框 + 红硬投影。
4. **Saira 只用于标题/徽记**，正文用系统字——宽体 900 当正文会挤爆行距。
5. **挑灰必须低于 `L .72`**（见第 3 节）。想在眼睛上"再灰一点"之前，
   先拿 `python tools/measure-ratio.py` 量一遍——这个坑连踩了四轮。
6. **纹理层要往 `.atmosphere` 上放**，别放 `body::before`：后者在 `.scene`（不透明）
   下面，写了也看不见。想让整页改色，先查 `.atmosphere` 现在铺的是什么。
