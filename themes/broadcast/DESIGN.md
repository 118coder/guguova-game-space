# BROADCAST · 深夜广播 · 设计规范与设计理念

> 一句话：**一帧被扫描过的胶片**——整版浅灰渐变，半融的黑胶当幽灵，
> 带刻度虚线的"路由"纹路斜穿画面，星芒衬线大写当台标，底下压一行幽灵字。
>
> 参考：`新主题5/深夜广播.png`（另见 `游戏启动器-深夜广播.png`）。
> `assets/{sparkle,route}.svg` 为本项目几何绘制。

---

## 1. 设计理念（为什么长这样）

原型是**深夜电视/广播的台标画面（ident）**：没有硬边，只有灰阶过渡、
扫描颗粒和一点星芒。因此：

1. **这套主题的顶边"什么都没有"。** 参考图顶部没有任何分隔线或色条，
   只有颗粒。所以 `body::after { height: 0; background: none }`，
   连 `.topbar` 的 `border-bottom` 都去掉了，只留一层从 `#e6e6e3`
   渐到透明的浅灰。**这是"参考图没有的东西不要自己加"的第三个案例**
   （另两个：RIOT 的顶带、RISO 的粗彩条）。
2. **灰阶层次就是这套主题的全部内容。** 参考图的构成是
   浅灰 ≈25% / 中灰 ≈22% / 白 ≈20% / 深灰 ≈8%——**没有一个强色**。
   所以主视觉的 `::before` 不是"一块底板"，而是一条 7 段的斜向灰阶
   （`126deg`，从 `#f4f4f1` 一路压到 `#7d7d77` 再回来），
   模拟胶片上的光晕。我们的历史问题正好相反：**偏亮、层次拉不开**。
3. **黑胶是幽灵不是实体**：`::after` 的 `opacity: .62 → .72`，
   它要"半融"在灰里，不能是一个清晰的圆盘。
4. **字要压得住灰**：灰阶一深，标题就必须更黑更实（衬线 + 星芒），
   否则一整套画面会糊成一片。这是这套主题里"图形不能盖过文字"的具体形态。

## 2. 视觉语言 → 实现映射

| 参考图里的语言 | 落地位置 | 关键值 |
|---|---|---|
| 胶片灰阶底 | `.hero-inner::before` 的 7 段 `linear-gradient(126deg)` | `#f4f4f1 → #7d7d77 → #e8e8e4` |
| 全局浅灰场 | `body` 的 `118deg` 渐变 + `#e2e2df` | — |
| 带刻度虚线路由 | `assets/route.svg`（`background-position: 74% 106%`，只露右下） | 78% auto |
| 半融黑胶 | `.hero-inner::after` | `opacity: .72` |
| 星芒衬线大写 | `assets/sparkle.svg` + 衬线标题 | — |
| 幽灵字 | `.hero-logo::before` | `opacity: 1`（灰深了之后才敢给满） |
| 无顶线 | `body::after` 高度 0 | 见第 1 节第 1 条 |
| 开屏 | `theme.json: "intro": "veil"` | 共用骨架，灰阶配色 |

`features.texture = film`（框架层的胶片颗粒通道），`type` / `panel` 不启用。

## 3. 量化验收

`python tools/measure-ratio.py --all`：

| 桶 | 参考 | 我们（当前） | 差 |
|---|---|---|---|
| light-grey | 25–26% | 26% | 到位 |
| paper | 22% | 45% | **+23（最大项）** |
| mid-grey | 22% | 16% | −6 |
| white | 20% | — | 待测 |
| dark-grey | 8% | — | 待测 |

> 关键认识：**我们的 `paper` 桶里混进了本该算 mid-grey 的浅暖灰**
> （分类器按亮度分档，`#e2e2df` 这类会被判成 paper）。
> 也就是说"paper 偏多"有一半是**分档边界**问题，不全是画面问题。
> 真正要做的仍是**把斜向灰阶压深一档**（已做：`#7d7d77` 段），
> 让中灰那一段真正落到 mid-grey 档里。

## 4. 不可回退的坑

1. **不要加顶线/顶带**（第 1 节第 1 条）。这是参考图明确没有的。
2. **黑胶不许"实"**：`opacity` 一旦给到 1，灰阶画面会突然出现一个硬圆。
3. **灰阶渐变不能过曝**：整条渐变里最亮处不许用纯白 `#fff`，
   参考图最亮是 `#f5f5f2`（胶片白不是屏白）。
4. **别用 `blur` 做柔焦**（项目铁律）。要"糊"就靠灰阶本身与颗粒纹理。
