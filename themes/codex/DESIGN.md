# CODEX · 星轨秘典 · 设计规范与设计理念

> 一句话：**一本暗色天文秘典**——深褐羊皮纸、双层烫金线、虚线内框、
> 红玉菱形刻度，开场是一座转动到位的星盘。
>
> 说明：本文只记录「为什么这样设计」与不可回退的规则；
> 色值与选择器以 `theme.css` 为准（签名层在文件末尾，按段落注释分隔）。

---

## 1. 设计理念

原型是**手抄秘典（codex）**：书页是暗的（不是白纸），金线是"压印"的，
刻度是"测量的"（星盘/量规），红玉菱形只出现在**刻度位**上——
它是"读数"，不是纯装饰。由此：

1. **暗底 + 金线 = 秘典**。和其他"羊皮纸"主题（GRIMOIRE）的区别在于
   亮度方向相反：GRIMOIRE 是"深色装帧 + 亮纸卡"，CODEX 是**整页都暗**，
   靠金线与虚线内框建立层次。
2. **刻度必须对应真实数据**。星盘/刻度环上出现的小方块是"量规刻度"，
   与进度、时长这类真实读数同源；不画无意义的徽记
   （GRIMOIRE 旧版菱形【15】的反面教材，见 `themes/grimoire/DESIGN.md`）。
3. **星点场是"纸的质地"而不是"夜景"**：`features.texture = starfield`
   的密度要低到能在上面印字（铁律 1）。

---

## 2. 通道声明（框架层）

| 通道 | 值 | 作用 |
|---|---|---|
| `texture` | `starfield` | 低密度星点场，当作暗纸的质地 |
| `type` | `foil` | 烫金字体图层（渐变 + 描边 + 内发光，Photoshop 式图层效果） |
| `panel` | `double` | 双层线框面板 |
| `intro` | `codex` | 星盘开场（**CSS-only preset，与多套主题共用骨架**） |

> 这套主题是「框架通道用得最全」的三套之一（另两套：MNEMO、ZERO HOUR），
> 改动 `src/theme-fx.css` / `src/fx-layers.css` 时**必须先看这三套**
> ——它们是通道的验收样本。

---

## 3. 不可回退的坑

1. **印章/徽记必须落在被裁切的滚动容器内**（`theme.css` 1552 段的修正）：
   曾经印章被 `overflow` 裁掉一半。改印章位置前，
   先用 `node tools/export-all.js --views=all` 跑一遍确认没被裁。
2. **星盘上的字必须可读**（同段修正）：星盘刻度一密，压在刻度上的文字就糊。
   星点/刻度的 `opacity` 上调前，先跑 `probe-graphics.js`（铁律 1）。
3. **烫金字体图层的描边宽度**不要超过字重的 6%，否则小字号（外观预览
   30–34px）会糊成一团。

## 4. 下一步

- **开屏要独立**：`codex` preset 与多套主题共用 astrolabe + `%` 计量条骨架，
  只是配色与节奏不同——按"每套主题的开屏必须不一样"，
  应换成自建舞台（参考语言：**秘典翻页 + 刻度归零**，
  与 GRIMOIRE 的火漆印完全不同）。
- 详情/外观铭牌的暗色处理已对齐首页（`theme.css` 1590 段），
  但**外观预览**的历史遗留（覆盖表标 `△`）还没统一成铭牌 + 编号条。
