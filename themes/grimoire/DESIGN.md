# GRIMOIRE · 设计规范与设计理念

> 一句话：**把启动器做成一本摊开的冒险者档案**——深色硬壳装帧、烫金双线框、
> 中间一张羊皮纸角色卡，卡上印的是**这台机器里真实存在的游戏数据**。
>
> 参考：`新主题2/冒险者档案.png`（另见 `游戏启动器-冒险者档案.png`）。
> 参考图只用于提炼语言，本文所有素材都是本项目几何绘制，未复制官方素材。

---

## 1. 设计理念（为什么长这样）

**档案（GRIMOIRE）而非"魔法书皮肤"。** 这套主题讲的不是"奇幻风配色"，
而是一个可被验证的隐喻：启动器 = 收藏册，每一个游戏 = 一页档案。
所以所有装饰都必须能回答一句话——**"这个符号对应哪一条真实数据？"**
答不上来就不许画上去。

反面教材（本轮删掉的）：旧版在标题右侧画了一枚菱形，里面写【15】，
看着像"等级徽章"。但启动器**没有等级概念**，15 既不是游玩时长也不是启动次数，
纯粹是抄参考图的形式，而且它还压在标题文字上（同时违反铁律 1）。
现在换成 **档案编号火漆印**：印的是当前选中条目在库里的真实序号，
和 dock 的 `No.01…No.10`、书脊编号同源；没有选中游戏时整枚隐去。
——同一位置的同一形状，一个是装饰，一个是数据。这就是这套主题的分界线。

**装帧要有份量。** 参考图的主体不是"一张纸"，而是"一本书"：
近黑的皮革外框 + 多层烫金线 + 内嵌的羊皮纸卡。所以卡不能贴边，
必须留出一圈**能被称为"书壳"的暗色 padding**（`.hero` 的 padding 就是装帧本身）。

## 2. 视觉语言 → 实现映射

| 参考图里的语言 | 落地位置 | 关键值 |
|---|---|---|
| 深色皮革装帧 | `theme.css` v4 段：`body` / `.scene` / `.dock` | `#140d07`（装帧）、`#1b120a`（dock） |
| 烫金双线框 | v5 段 `.hero-inner::before` 的多层 `box-shadow` | 1px 亮金 / 4px 金 / 11px 暗金带 / 外 15px 金边 |
| 羊皮纸卡 | `features.texture = parchment`（框架层，非本主题私有） | 纸色 `--gs-parchment` |
| 酒红标题条 / 进度条 / 活动条 | `.tile-label`、进度与活动元素 | `--gs-maroon` |
| 插画像"嵌进书壳" | v4.1 段 `.scene > img` + `.scene::after` 暗角 | `sepia(.42) saturate(.78) contrast(1.08) brightness(.45)` |
| 档案编号火漆印 | `features` 无关，签名层 + `src/fx-record.js` 的 `--nova-no` | 未选中时 `opacity:0` |
| 开屏：归档仪式 | `theme.json: "intro": "seal"`（`src/intro.js` 的 `seal` preset） | 火漆砸下 → `No.06` 落定 → `已归档` |

**为什么暗角放在 `.scene::after` 而不是 `.hero`：见第 4 节坑 #1。**

## 3. 量化验收（配色占比）

口径：`python tools/measure-ratio.py --all`，实机截图取左 66% × 垂直 9%–72%
（这一块几乎就是羊皮纸卡本身）。

| 桶 | 参考 | 我们（v5） | 差 |
|---|---|---|---|
| paper | 46.7% | 49.2% | +2.5 |
| red | 21.0% | 20.7% | −0.3 |
| black | 12.2% | 12.9% | +0.7 |
| orange | 11.8% | 11.2% | −0.6 |
| yellow | 3.5% | 1.7% | **−1.8（未收）** |

唯一剩下的黄：加宽卡内那道**浅金细线**即可，**不要去动标题**（铁律 1）。

铁律自检：`export-all.js` 全视图 + `--stress`（40+ 字长名）**0 告警**；
`probe-graphics.js` 不压字；火漆印不叠正文。

## 4. 不可回退的三个坑

1. **绝不能用 `.hero { box-shadow: inset … }` 做金边。**
   hero 的那圈 padding **就是**黑色装帧；inset 阴影会把这一圈涂掉，
   黑占比实测从 6.5% 跌回 3.0%，方向完全反。金边一律走
   `.hero-inner::before` 的多层 shadow，暗角走 `.scene::after`。
2. **多层 `box-shadow` 是按书写顺序从窄到宽**：细亮金线必须写在宽带**之前**，
   否则被宽带盖住（v5 第一版就写反了）。
3. **符号必须有真实数据对应**（第 1 节）。新加任何压在标题区的图形前，
   先问它印的是 `--nova-no` / `--nova-count` / `--nova-hours` 里的哪一个。

## 5. 已知取舍（需要人来定）

- 插画被压到 `brightness(.45)`：数值与暗环都对了，但"插画压这么暗是否可接受"
  是审美决定。要提亮就把 `theme.css` 末尾 v4.1 段抬到 `.6–.7`，
  代价是 paper 回升约 3–4pp。
- 火漆印只在**选中游戏**时出现（空库时整枚隐去）——这是刻意的：
  没有数据就没有符号。
