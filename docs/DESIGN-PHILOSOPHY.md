# NOVA 设计理念与主题维护手册

> 适用版本：**1.5.3**
> 最后整理：2026-10-20
> 配套文档：`docs/HANDOFF-NEXT.md`（下一轮交接）、`docs/HANDOFF.md`（项目全貌）、`docs/HANDOFF-THEMES.md`（本轮细节）、
> `docs/THEME-INTERFACES.md`（接口契约）、`docs/themes/*.md`（单主题卡）、
> `docs/SFX-MAP.md`（音效触发表）。

这份文档回答三个问题：

1. NOVA 的主题到底在追求什么？
2. 一套主题由哪些层组成、哪些可以变、哪些绝不能变？
3. 后续新增/修改主题时，按什么顺序做、怎么验收、怎么发版？

---

## 1. 产品定位

NOVA Game Space 是**离线单机游戏启动器**，不是在线社区，也不是游戏平台客户端。

- 不登录、不联网、不上传；
- 游戏库、封面、游玩记录、头像、设置都保存在本机；
- 迁移靠 `.nova-pack` 数据包，不依赖服务器；
- 主题是“界面语言”，不是换色皮肤：每套主题拥有自己的版式、控件、字体角色、
  开屏、进游戏动画和切换动画。

设计目标只有一句话：**像一台真正属于玩家的游戏主机，而不是一个网页套壳。**

---

## 2. 六条不可违反的规则

1. **图形不得盖过文字。** 任何装饰、线稿、照片、网点、胶带、印章都不能压住主体文字；
   文字必须有足够的对比度和干净的落点。
2. **不得出现文字截断。** 标题用 `.is-long-title` / `--logo-fit` 自适应；主题写死
   `font-size` 时必须乘 `var(--logo-fit,1)`；禁止 `nowrap + ellipsis` 处理主标题。
3. **必须用 30 个汉字 + 冗余的游戏名测试。** 1440×1124 与 960×600 两档都要看。
4. **主题顺序固定前四。** `NOVA → 终末地 → 零点街区 → 秘典`；其余按使用次数，
   只在启动时排序一次，会话内不重排。
5. **缓存不落 C 盘。** 开发用 `NOVA_CACHE_ROOT`（E: `.cache/webview2`）；
   正式默认优先选非 C 的固定磁盘，只有单盘机器才回退到 C。
6. **每轮改动必须更新交接/设计文档。** 设计理念、接口、版本表、单主题卡至少改一处，
   不能只改代码。

## 3. 统一设计系统

### 3.1 颜色层级

每套主题可以有自己的色板，但层级语义一致：

| 层级 | 用途 | 例子 |
| --- | --- | --- |
| 纸/底 | 页面最大面积 | 白纸、羊皮纸、深褐铜版、黑街 |
| 墨/主文字 | 正文与标题 | 近黑、米白 |
| 强调色 | 当前位置、主操作、可点击 | 酸黄、青柠、朱红、鎏金 |
| 次强调 | 数据、辅助线、次操作 | 青蓝、梅红、琥珀 |
| 危险色 | 只给删除/失败 | 红 |

规则：

- 强调色只做**填充**，不要大面积铺成背景；
- 浅色主题里强调色不能当正文颜色；正文用墨色；
- 红色只给删除/失败，不拿来做普通提醒；
- ZERO HOUR 的主色是**青柠 `#c6ff2e`**，青色 `#59e3ff` 做次强调；
  黄色 `#ffe600` 只给“注意/警示”，切换动画里不出现黄色字。

### 3.2 字体

全主题使用本机 **思源黑体 CN Medium / 思源宋体**，不内置西文字体。

| 令牌 | 用途 | 推荐栈 |
| --- | --- | --- |
| `--font-ui` | 正文、控件 | 思源黑体 Medium |
| `--font-display` | 标题、字标 | 按主题配黑体 Medium 或宋体 Medium |
| `--font-serif` | 衬线正文/书页 | 思源宋体 |
| `--font-condensed` | 大号标签 | 按主题配黑体/宋体 |

标准栈（直接复制）：

```css
--font-ui: "思源黑体 CN Medium", "Source Han Sans CN Medium", "Noto Sans SC Medium", "Microsoft YaHei UI", "Microsoft YaHei", sans-serif;
--font-serif: "思源宋体", "Source Han Serif SC", "Noto Serif SC", "Songti SC", "SimSun", serif;
```

- Regular 家族名在 WebView2 中不稳定，**统一用 Medium 家族名**，粗体由 Chromium 合成；
- 衬线标题用 `思源宋体 Medium`，正文衬线用 `思源宋体`；
- 不再新增指向主题目录字体的 `@font-face`；需要特殊字体时用 `local()` 或随包附带 OFL 字体并登记许可。

### 3.3 版式

- `.view` 绝对铺满内容区，带 `contain: layout style`，过渡只动 `opacity/transform`；
- 首页是主视觉 + 底部游戏条；游戏库/外观/设置是独立全屏视图；
- 设置页是**全宽双栏控制台**：`width: min(1640px, 100%)`，左列玩家/数据/统计，
  右列启动/兼容性/关于；`≤1080px` 自动单列；
- 所有标题、统计值、长路径都要允许换行或等比缩放，不允许省略号吃掉半个词；
- 导航的英文眉标必须四页齐全：`// HOME` / `// LIBRARY` / `// LOOK` / `// SETTINGS`
  （秘典用 `IV · 设置`，MNEMO 用 `// 04`）；缺一页就是设计缺口；
- “字标方案/字体设定”等小字必须过 4.5:1 对比度；暗底主题用提亮后的次级色，
  不要直接把 40% 透明度的墨色用在小字号上；
- “NOVA 默认”只切换字标配方，**不接管其他主题的面板/开关/导航底色**；
  `html.is-nova-system` 的编辑器外观规则必须限定在 `html[data-theme="nova"]` 下，
  否则浅色主题会被强制成黑面板，出现“默认模式看不清”的问题；
- 设置页顶部用户卡是“玩家身份”的第一落点，必须按主题设计，不能套统一玻璃卡。

### 3.4 动效

动效原则：**短、硬、机械、每次操作只对应一次运动。**

| 曲线 | 值 | 用途 |
| --- | --- | --- |
| snap | `cubic-bezier(.16,1,.3,1)` | 入场、落位 |
| mech | `cubic-bezier(.7,0,.2,1)` | 退出、硬切、快门 |
| soft | `cubic-bezier(.4,0,.2,1)` | 轻微淡入 |

- 单次 UI 响应 100–400ms；整套开屏不超过约 2.4s；
- 全屏层禁止 `filter` / `backdrop-filter`；只允许 `transform / clip-path / opacity`；
- 不做持续循环的装饰动画；`prefers-reduced-motion` 或 `safe` 档全部静止；
- 主题切换的幕布必须能完整看到“覆盖 → 换样式 → 揭开”，第一次切换也一样。

## 4. 每套主题的三个动画

每套主题必须有**不同**的：

1. **开屏 intro**：开机仪式，展示品牌/日期/时间/游戏数等真实数据；
2. **进游戏 launch**：从点击开始到启动画面的过渡；
3. **主题切换 curtain**：换样式表时遮住重算的幕布。

### 4.1 切换编舞表（`#themeCurtain[data-variant]`）

| 主题 | 动作 | 覆盖 | 记忆点 |
| --- | --- | --- | --- |
| NOVA | 上下双幕布 + 中央光缝 | 360ms | 电影遮幅 |
| AURUM | 左右青铜门 + 竖金缝 + 门环 | 400ms | 鎏金圣所大门 |
| ENDFIELD | 蓝图面板横扫 + 38px 切角 + 三色条 | 380ms | 工程图纸推进 |
| ZERO HOUR | 漫画分页：黑板 + 白框分镜 + 青柠字幕带 + 速度线 | 420ms | 青柠/青蓝，无黄色字 |
| CODEX | 整页绕顶边 3D 翻下/翻开 | 430ms | 书页翻动 |
| BROADCAST | CRT 开机闪白 → 收成横线 | 360ms | 老电视 |
| SUMMER | 白纸印版扫入 + 黑/黄块压版 | 470ms | 印刷排版 |
| RISO | 蓝/纸双印版反向错位 | 380ms | 套印错版 |
| RIOT | 朱红褶皱舞台幕布 + 撕胶带缝 | 380ms | 演出开场 |
| GRIMOIRE | 羊皮纸页上升 + 蜡封落下 | 650ms | 档案页翻开 |
| MNEMO | 纵向记忆条带 + 紫色重影 | 360ms | 内存扫描 |

实现要点：

- `playThemeCurtain()` 写 `dataset.variant`，先在 `is-on` 状态等两帧，再 `is-cover`；
  这样第一次切换也能看到完整动画；
- `CURTAIN_HOLD` 必须 ≥ 该变体最长覆盖动画；
- 全屏面板用 101% 位移或足够大的 clip-path，保证四角完全覆盖；
- 幕布中央文字固定字体（思源宋体/黑体），不继承会随主题变化的 `--font-display`；
- 幕布中央主题名只显示“·”前的部分（如“舞台残响”）。

### 5.1 NOVA · 电影感主机

- **一句话**：像一台默认的次世代主机，画面是电影主视觉，界面退到边缘。
- **概念**：不做纸面、不做漫画、不做工业标签。全屏封面 + 暖色辉光 + 左下沉稳的文字板；
  主题本身不覆盖布局，只提供默认的电影感基调，是其他主题的“中性基线”。
- **色彩**：封面自适应；默认暖橙 `#ffa477`、珊瑚 `#ff6f6f`、近黑底、米白字 `#f5f2ea`。
  强调色来自当前游戏封面，但只用于按钮、进度和选中，不铺满背景。
- **字体/排版**：思源黑体 Medium 负责 UI 与标题；思源宋体只用于字标/衬线强调。
  8 套字标配方（gilded/poster/grotesk/inscription/boutique/monolith/kinetic/outline）
  靠字重、字距、大小写、描边和渐变区分，不靠换字体文件。
- **构图**：全屏主视觉铺底，左侧信息板，底部游戏条；暗角压住边缘，文字始终在深色底上。
  没有额外几何框、没有插画窗、没有胶带。
- **控件**：主 CTA 用封面取色渐变 + 柔和高光；ghost 为细描边；圆角保持默认的中等圆角。
- **动效**：开屏 `gilded` 星核；进游戏 `nvLaunch` 变形宽银幕细缝；切换上下双幕布 + 中央光缝（360ms）。
- **设置用户卡**：暗色玻璃，暖橙边缘光，头像带暖色环；整体最“安静”，不抢主题。
- **禁忌/维护**：不要给 NOVA 加纸纹、硬偏移、漫画网点或大面积强调色；它是所有主题的 fallback，
  任何全局改动都要先确认 NOVA 不被弄脏。

### 5.2 AURUM · 鎏金圣所

- **一句话**：一座墨绿与鎏金的仪式空间，像进入圣所前的登记台。
- **概念**：仪式感优先于科技感。深绿铁底、青铜金线、青玉能量点；主视觉是羊皮纸铭牌，
  不是照片或插画。所有装饰都要像“铸”上去的，而不是贴上去的。
- **色彩**：墨绿底 `#070b0a / #131a15`；鎏金 `#e0bd7e`；青玉 `#5fd6c6`；文字 `#ede3cd`。
  金色只做线、标题和主按钮；青玉只做小点/次强调，不要大面积铺。
- **字体/排版**：思源宋体标题 + 宽字距；思源黑体 Medium 正文。标题要有“铭刻”感，
  字距略宽，行距紧凑；正文保持小字号可读。
- **构图**：暗色面板 + 双层金线框 + 菱形/罗盘/青玉点；主视觉板居中偏左，右侧留出仪式空间。
  不用照片窗，不用圆角卡片。
- **控件**：金线描边 + 深底；主按钮暗金渐变、深色字；ghost 只有金线；圆角很小或为 0。
- **动效**：开屏 `aurum` 金门；进游戏 `auLaunch` 菱形光圈；切换左右青铜门 + 竖金缝 + 门环（400ms）。
- **设置用户卡**：青铜牌匾，方形/近方形，金色双线、四角括号、金色圆环头像，姓名用宋体宽字距。
- **禁忌/维护**：不要用霓虹紫/蓝、不要大圆角白卡、不要把金色铺成背景；金线必须细，
  装饰不能压住铭牌文字。

### 5.3 ENDFIELD · 终末地

- **一句话**：一本现场工程手册，白纸、墨线、酸黄信号，像工业设备的操作台。
- **概念**：结构优先。纸白底 + 墨黑线 + 唯一酸黄；切角表示“可以按”，直角表示“只是展示”；
  宽体大写拉丁字在上、粗体中文在下；真实编号/日期/计数就是装饰。
- **色彩**：纸白 `#f4f4f2`、墨黑 `#161616`、酸黄 `#fffa00`；三色条只用
  品红/酸黄/薄荷绿，且只出现在页面开头和详情标题下。红色只给删除。
- **字体/排版**：全篇思源黑体 Medium；英文标签全大写、字距约 0.14em；中文粗体、不额外拉字距；
  数字用 tabular figures。标题可做实心/空心双字标。
- **构图**：白纸大面积留白，1px 墨线分区，切角画框 + 45° 斜线纹影子；主视觉板是“工程铭牌”，
  不是照片卡。底部信息用编号/字段行，不排成圆角卡片。
- **控件**：切角块；桌面主按钮静止墨底、悬停酸黄擦入；触屏静止就是酸黄底黑字；
  ghost 只用细线；圆角一律 0，阴影只用硬边斜线纹。
- **动效**：开屏 `endfield` 启动序列（真实日期/时间/游戏数 + 乱码落定）；进游戏 `efLaunch` 工业闸门；
  切换蓝图面板横扫 + 38px 切角 + 酸黄立边 + 三色顶带（380ms，snap/mech）。
- **设置用户卡**：工业标签，2px 墨边、方形角、酸黄方形头像、酸黄标签；开关是方形黄/黑块。
- **禁忌/维护**：不要圆角、柔光、渐变铺底；不要把酸黄当正文颜色；不要放假技术文字；
  切角里不能压字，留白要跟着切角变大。

### 5.4 ZERO HOUR · 零点街区

- **一句话**：黑街漫画 + CRT 命令台，青柠是“当前”，青蓝是“信号”，黄色只是“注意”。
- **概念**：厚墨边、硬偏移影、网点、胶带、扫描线；像街头终端和漫画分镜的结合。
  信息层级靠块面和描边，不靠阴影柔光。
- **色彩**：近黑 `#08090a`；青柠 `#c6ff2e`（当前/选中/主操作）；青蓝 `#59e3ff`（次强调/数据）；
  纸白 `#f1efe7`；黄色 `#ffe600` **只给注意/警示**，不用于普通标题或切换动画文字。
- **字体/排版**：全篇思源黑体 Medium；大写字段、硬边、tabular-nums；标题可以很重、很紧。
- **构图**：黑底 + 网点 + 分段信号轨 + L 形角标 + 斜纹面板；主视觉板有厚墨边框，
  像漫画分镜；不要让装饰线穿过标题。
- **控件**：黑底 + 青柠描边；选中态为青柠实块、黑字；次操作青蓝；禁止圆角大卡片和柔光。
- **动效**：开屏 `zerohour` CRT 信号接入；进游戏 `zhLaunch` CRT 同步；

### 6.1 手柄交互（重点）

手柄模式不是“再加一套快捷键”，而是让手柄能操作**当前屏幕上的真实 DOM 焦点**。

- 连接手柄后，焦点进入当前视图的第一个可操作项，并显示主题强调色焦点环
  （`html[data-input="gamepad"] .is-pad-focus`）。
- 方向键 / 左摇杆：按**阅读顺序**移动焦点；上下左右都可用，保证两栏设置不会跳过整组选项。
- A / ✕：点击当前焦点；`<select>` 用 A 循环选项并派发 `change`；文本框用 A 聚焦后提示用键盘输入。
- B / ○：返回；对话框相当于 Esc，文件选择器点击关闭。
- LB/RB：首页切换游戏；外观页切换预览游戏；设置/库/列表页滚动。
- X / □：收藏；Y / △：详情页管理、外观页重排字标；Menu / OPT：游戏库；
  View / SHARE：通知；LS / L3：外观；RS / R3：设置。
- 所有设置页控件——头像、名称、保存、使用 Windows 用户名、导出/导入、CSV、打开文件夹、
  开关、效果档位、关闭按钮——都在焦点列表里，不允许“手柄点不到”。
- 对话框和文件选择器打开时自动聚焦第一个操作，方向键在按钮/文件行之间移动，A 确认、B 取消。
- 简化：装饰性、纯文本、不可操作元素不进入焦点列表；可用 `data-pad-skip` 标记重复项。
- 焦点环只画在焦点元素外侧，不覆盖文字；手柄提示条按当前屏幕切换文案。

实现位置：`src/gamepad.js`（轮询/按键）、`src/app.js` 的 `padSurface / padFocusableList /
padMoveFocus / padActivate`（焦点导航）、`src/focus.js`（强制焦点留在最上层表面）。

## 7. 音效设计

- 全部为**离线本地合成音效**（genny 生成，无第三方采样），来源与复现方式见
  `src/assets/sfx/LICENSE-SFX.md` 与 `tools/sfx-specs/`；
- **每套主题有自己的一套 16 个 cue**，放在 `themes/<id>/sounds/`；
  内置 NOVA 放在 `src/assets/sfx/nova/`。材料必须对应该主题的设计理念：
  终末地是继电器/打字机，零点街区是 CRT/街机，冒险者档案是纸页/蜡封，etc.
- 主题音效**完全替代**统一音效，不叠加；缺文件时自动回落到 `src/assets/sfx/`；
- 开屏音效 `boot` 是按该主题开屏关键帧排好的序列，与动画同时启动；
- 设置页可切换 **使用默认统一音效**（`unifiedSfx`），立刻生效；
- 触发映射见 `docs/SFX-MAP.md`；
- 生成规格：`tools/sfx-specs/build-themes.py` → `genny render` → ffmpeg 转 OGG；
- 建议单声道 44.1kHz、峰值 ≤ -1dB、时长 < 1.5s（开屏序列除外）；
- 生成后必须跑 `genny info`：`sharp ≤ 2.0`、`above5k ≤ 3%`（噪声类转场略高可接受）；
- **雪花噪/白噪声要慎用**：只允许出现在「切换主题 / 失败 / 开屏底噪」这类转场，
  且必须低通（≤3.6kHz）并压高频；点击、悬停、确认一律不要宽带噪声——
  它们是最高频的音效，噪声会立刻变成刺耳。
- 每套主题最多保留 1–2 个带噪声的 cue，其余用该主题的实体材料（纸、木、金属、玻璃）。
- 不要把音效做成持续循环；不要联网加载。
- 终末地开屏使用随包字体 **Saira**（OFL 1.1，`src/assets/fonts/Saira.ttf`，
  许可证同目录）；其他主题不得依赖该字体，缺失时必须回落到思源黑体。

| `balanced` | 较旧 WebView2 / 无 color-mix | 关闭部分混合与滤镜 |
| `safe` | Win7/8.1 或低性能 | 关闭开屏、装饰、动画 |

- Modern：.NET 10 + WebView2 evergreen；
- Legacy：.NET Framework 4.8 + WebView2 109，单文件 EXE；
- 全屏视图禁止 `backdrop-filter`；主题切换只动合成属性；
- 首屏后 idle 预取主题 CSS；第一次切换也必须完整（幕布先画初始态再启动）；
- 缓存默认避开 C 盘；开发缓存用 `NOVA_CACHE_ROOT`。

## 9. 版本与维护流程

### 9.1 新增/修改主题

1. 改 `themes/<id>/theme.css` 与 `theme.json`；
2. **bump `theme.json` 的 patch 版本**（缓存失效）；
3. 视觉有变化就重画 `assets/preview.jpg`：
   - 概念板源：`tools/theme-concepts.html`
   - 渲染：`node tools/render-concepts.js <out> --only=<id>`
   - 缩到 960×540 JPG；
4. 同步到 `%LOCALAPPDATA%\NOVA Game Space\themes\<id>` 并重启；
5. 跑审计：`export-all.js --views=home,library,appearance,settings,detail --sizes=1439x1124,960x600 --stress`；
6. 更新 `docs/themes/<id>.md` 与 `docs/THEME-INTERFACES.md` 版本表。

### 9.2 新增主题

1. 复制主题目录，改 `id/name/version/preview`；
2. 在 `theme.json` 里只声明需要的 `features`；
3. 写 `theme.css`（基础层 → 修正层 → 签名层，后写覆盖先写）；
4. 在 `src/intro.js` 注册开屏 preset，加入 `STAGE_SELECTOR` 和清理类列表；
5. 在 `src/motion.css` 写新的 `data-variant` 切换编舞；
6. 在 `src/settings-themes.css` 写设置控件与身份卡；
7. 生成 16:9 预览，更新文档与版本表；
8. 跑审计 + 30 字长名测试 + 单文件 Legacy 验证。

### 9.3 发版

```bash
node tools/bump-version.js 1.5.x   # 同步 Modern/Legacy csproj、index.html、version.json
bash tools/pipeline.sh             # 审计 + Legacy 构建 + 单文件/全主题包
```

- `version.json` 是唯一版本源；
- 两个 Legacy 包与 Modern 包共用 `library.json` / `.nova-pack`；
- 发布前确认：版本、主题表、预览图、音效许可、30 字测试、首次切换动画、缓存位置；
- 变更提交 PR 并合并。

## 11. 常见坑（不要再踩）

1. `fit-content` 标题的可用宽度不要取自身宽度，取父级文字列；否则字号和宽度互相追赶。
2. 不要给 `.logo` 的 `letter-spacing` 做过渡；它会让 fitLogo 每帧重测。
3. 主题切换的幕布先画初始态再启动；第一次切换和第二次必须一致。
4. 导航滑块在主题切换时直接吸附（`.is-instant`），不要从旧宽度滑到新宽度。
5. 全屏层禁止 `filter/backdrop-filter`；用 transform/clip-path/opacity。
6. 幕布中央文字用固定字体，不继承主题变量。
7. ZERO HOUR 不要用黄色字；黄色只给注意/警示。
8. SUMMER 不要在角色脸上压黑色线稿；线稿只用青色。
9. 主题预览要反映当前真实语言，不要放已删除的插画/线稿。
10. 缓存及时清理，且不要放 C 盘；提交前清 `.cache`。
