# DUSK · 黄昏之炼 —— 设计规范

## 0. 2.3 委托信（当前实现）

2.0 的书页 + 拱形画框已被判定「太像卡片」。2.3 把主区改成**钉在工房板上的委托信**：

1. **天幕**：`.app::after` 仍是暮色天幕 + 太阳 + 远山 + 炼金环，作为背景。
2. **信纸**：`.hero-inner` 是撕边纸（`clip-path` 12 点撕边），`rotate(-.45deg)`；
   背景是旧纸噪点 + 污渍 + 边缘压暗 + 暮色染色；**不再有书脊、皮革包角、拱形画框**。
3. **图钉与麻绳**：`.hero::before` 一枚黄铜图钉 + 一条斜拉的陶土色麻绳；
   纸面另有四个小图钉（背景径向渐变）。
4. **贴照**：`.hero-inner::after` 是 300×187 的委托人照片，8px 纸白边、两角胶带、
   `rotate(1.8deg)`；照片来自 `--nova-hero`。
5. **委托标记**：`.kicker::before` 输出「委托」；`progress-block::before` 是
   「已受理 · ACCEPTED」陶土章；`progress-block::after` 是手写署名；
   `.hero::after` 是右下角封口的火漆印。
6. **折痕**：`::before` 在 33% / 66% 处两条极淡的横向折痕 + 双金线内框。

**切换动画**改为**拆信封**：`.tc-top` 是信纸，从下方升起；`.tc-bottom` 是三角封盖，
以顶边为轴折回封口（`rotateX(-180deg) → 0`）；红绳在封口处收紧。揭开时封盖先翻开，
信纸再抽走。与 Steam 的 tile 放大、Night 的票根对撕完全不同。

**无模糊**：`.appearance-bg`、`.detail-art::before`、`.launch-bg` 全部禁用；
所有 `backdrop-filter` 置 none；外观预览改用清晰的暮色渐变底。

## 0b. 2.0 构图（历史）

1.0 的「横放米色表单 + 右上贴纸 + 右栏进度」已整体废弃。2.0 的一页工作台由七件东西组成：

1. **天幕**：`.app::after` 画靛蓝 → 紫 → 玫瑰 → 琥珀的暮色，含低垂太阳、远山剪影、
   鸟群、星点与一圈刻在天幕上的炼金环（不发光）。
2. **书脊**：`.hero::before` 是一条 36px 的深色书脊，竖排烫金「黄昏之炼 · DUSK ATELIER」。
3. **纸页**：`.hero-inner` 为羊皮纸，`::before` 画内缩 9px 的双金线与四角金点；
   背景另含左下角炼金环水印与一条页脚金线。正文垂直居中，不再把空白堆在纸页底部。
4. **拱形画框**：`.hero-inner::after` 是右栏 34% 的拱形画框（`50% 50% 4px 4px / 30% 30%`），
   外层 7px 纸白 + 1px 金边，内部放 `--nova-hero`。
5. **火漆印**：`.hero::after` 压在纸页右上角，深红圆印 + 纸色反光，`rotate(-12deg)`。
6. **丝带眉标**：`.kicker` 用纸色丝带 + 切角，陶土字，承载「委托 · 上次委托」。
   文案来自 `theme.json` 的 `lexicon.lastPlayed = 上次委托`，切换主题时由 `themeWord()` 即时重绘。
7. **页脚**：底部一条金线 + 中央菱形，与左下角炼金环水印一起补足纸页的负空间。

配色：暮蓝 `#141126`、靛 `#221d3a`、玫瑰 `#93626a`、余烬 `#c87a52`；
纸 `#f7edd8` / `#eddec2`；墨 `#30251a`；陶土 `#a9503a`、青玉 `#4f7d72`、金 `#b58a4b`。
按钮：陶土红渐变 + 金边 + 内嵌亮线；次按钮为纸白 + 墨线。
开屏 `.intro-dk2`、进游戏 `dlDusk`、切换 `[data-variant="dusk"]`（拆信封 + 火漆印）。

## 0. 为什么是「黄昏之炼」而不是「炼金皮肤」

黄昏系列在系列里是特殊的一支：世界正在走向终结（Dusk），但界面不阴森，
反而到处是**暮色、旧纸、暖光、手写编号**。它给人的不是「魔法特效」，
而是**一间还有人认真工作的工房**。这套主题就照这个来：

- 玩家看到的不是「一个网站套了奇幻配色」，而是一张**还带着温度的工作台**；
- 所有刻度、编号、日期都必须是真实数据（`introData` / `fx-record.js` / 本机时长）；
- 装饰只允许是**纸、墨、光线、刻度**，不允许出现符文、魔法阵特效、发光粒子。

1. **冷底 + 暖光**：靛蓝夜空是底，琥珀夕阳是唯一光源；暖色只出现在「正在发生的事」上。
2. **纸是工作区，不是装饰**：信息必须落在纸面上，纸外只有天色。
3. **刻度即叙事**：进度不是一根彩色条，而是带刻线的量尺；这来自调和界面的四元素槽。

## 3. 字体与排版

| 角色 | 字族 | 用法 |
|---|---|---|
| 标题 / 游戏名 / 数字 | 思源宋体 700 | 字距 `.015em`；中文标题可两行，禁止省略号 |
| 正文 / 控件 | 思源黑体 Medium | 小字号不加字距，保证 12px 可读 |
| 拉丁眉标 | 思源黑体 Medium | 全大写，字距 `.26em`–`.46em`，只做「标签」 |
| 编号 / 时刻 | 思源宋体 + `tabular-nums` | 真实日期、时长、No. 编号 |

排版细节：

- 眉标前有一条 26px 细线（像档案页的引导线），后面跟圆点与浅色说明；
- 主标题下有一条 64px 陶土短线，作为「落款」；
- 属性行用 14px 横线替代圆点分隔，读起来像表格；
- 长名（>14 字）自动两行、字号降到 clamp(24–44px)，`overflow-wrap:anywhere`。

- **纸外只有天色**：主视觉板是唯一的信息载体，不铺满整屏；

- **装订孔 + 左缘双线**由 `.hero-inner::before` 的背景图案绘制，透明度 < 0.3；
- 宽度：`min(1180px, 80vw)`；`≤1180px` 收成单列并隐藏取样（避免文字被挤）；
- `≤760px` 高度时进一步压缩标题与按钮，隐藏书脊与进度，保证不出现滚动条。

## 5. 控件配方

| 控件 | 做法 |
|---|---|
| 主按钮 `.btn.primary` | 陶土红纵向渐变 + 1px 深红边 + 顶部内高光 + 2px 实底阴影；圆角 2px；文字米白 |

## 6. 三套动画

### 6.1 开屏「暮色开工」（`intro: dusk`，2600ms）

| 时间 | 动作 |
|---|---|
| 0–900ms | 暮色天空从上方压下（`scaleY .82 → 1` + 淡入） |
| 160–1360ms | 低垂的太阳升起、光晕展开（`translateY 34px → 0`） |
| 340–1140ms | 地平线自左向右画出（`scaleX 0 → 1`） |
| 280–1680ms | 炼金环描线（`stroke-dashoffset 1483 → 0`，同时从 -42° 转正） |
| 460–1340ms | 「黄昏 / 之炼」两行从遮罩里升起 |
| 500–1200ms | 眉标淡入；740ms 拉丁副标画线；900ms 台账行淡入 |
| 全程 | 台账显示真实日期、时刻、库内藏本数；右下百分比由 `runMeter` 走真实进度 |

降级：`reduce-motion` 时所有关键帧静止为最终态，仍显示真实数据。

### 6.2 进游戏「暮色合拢」（`dlDusk`，560ms）

封面从画面中心偏下的一枚圆形光斑开始扩散（`clip-path: circle`），
同时从「低饱和暗部」回到正常亮度——像黄昏最后一段光推开整幅画面。
不使用缩放弹跳，不使用模糊滤镜。

### 6.3 切换「暮色合拢幕布」（`data-variant="dusk"`，460ms）

- 上半片是**天空**（靛蓝→玫瑰），下半片是**羊皮纸**（带 ledger 横线），
  两片沿一条 4–6% 的斜边合拢，接缝处是一条琥珀地平线；
- 中央标签下有一圈虚线炼金环，随标签淡入缓慢旋转 24°；
- 揭开时两片沿原路退回，环反向转出；全程只动 `transform` / `opacity`。

## 7. 声音（16 cue）

材质：陶铃、木、纸、玻璃瓶、低音弦；**没有宽带噪声**，只有 `switch` 用一层低通到 2.6kHz 的风声。

| cue | 材料 | 时长 |
|---|---|---|
| bong | 低陶铃 196Hz + 陶铃 392Hz | 0.75s |
| click | 木鱼 1.3kHz + 纸 | 0.12s |
| nav | 木 980Hz + 玻璃泛音 | 0.16s |
| soft | 纸刷 | 0.20s |
| select | 玻璃瓶 1.98kHz + 陶铃 | 0.34s |
| confirm | 陶铃二音 523→784Hz | 0.70s |
| error | 低陶土闷响 118Hz + 暗噪声 | 0.55s |
| tick | 木 1.68kHz | 0.07s |
| chime | 玻璃三音 784/1046/1318Hz | 1.37s |
| deep | 低音弦 65Hz | 1.10s |
| launchRise / launchFall | 低弦 + 上/下行音 | 0.90 / 0.80s |
| switch | 低通风声 + 174Hz 缝线 | 0.55s |
| launch | 陶铃 + 低弦 | 1.00s |
| exit | 低闷响 + 纸收尾 | 0.62s |
| boot | 风 → 陶铃 → 玻璃 → 低弦 → 钟声（对齐开屏） | 2.72s |

全部为脚本合成：`tools/sfx-specs/make-dusk-sfx.py` → `ffmpeg -c:a libvorbis -q:a 5 -ac 1`。
实测高频（>5kHz）能量比满量程低 15–23dB，符合「点击/悬停不用噪声」的约定。

## 8. 禁忌（做了就不像黄昏之炼）

1. 不要霓虹、赛博网格、荧光描边；
2. 不要发光魔法阵、粒子、火焰特效——炼金环只能是**一条细线**；
3. 不要把菱形当装饰（菱形在本项目只表示等级）；
4. 不要给纸面加大圆角、玻璃模糊、柔和投影；
5. 不要在纸面用琥珀/金色写正文（对比度不足）；
6. 不要让封面取样压到文字列，也不要把胶带贴到标题上；
7. 不要把「四元素」画成装饰图标：它只能是进度/刻度的形状来源；
8. 不要伪造数值：日期、时刻、藏本数、时长全部来自本机；
9. 不要在切换动画里出现第二种强调色；
10. 不要把主题做成「深色奇幻」——底色是暮色，不是黑夜。

## 9. 验收

```bash
node tools/export-all.js --themes=dusk --views=all \
  --sizes=1439x1124,960x600 --stress
node tools/probe-graphics.js
```

- 30 字长名不溢出、不截断，两档尺寸都过；
- 纸面板内文字与装饰的最近距离 ≥ 12px；
- 960×600 不出现纵向滚动，进度块按规则收起；
- 12 套主题的卡片缩略图来自同一套概念板骨架（`tools/theme-concepts.html`）；
- `reduce-motion` 与 `data-tier="safe"` 下不播放任何关键帧动画。
