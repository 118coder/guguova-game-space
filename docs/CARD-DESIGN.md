# 分享卡片设计基准（CARD DESIGN BASELINE）

> 本文档是分享卡片（相机键 → 三规格导出卡）的设计基准：每套主题的卡片必须
> 让人一眼认出「这是这套主题的东西」，参照物是 **该主题开场动画的最终画面**
> （Owner 设计，`src/intro.css` 是唯一权威来源）。本轮（§1.27）覆盖 12 套主题；
> `nova`（默认）与 `endfield`（终末地/明日方舟，刚按 endfield-ui 重做过）不在范围内。
> 规格与红线：`docs/THEME-INTERFACES.md` §16.5；几何与 DOM：`src/share-cards.css`。

## 0. 方法：怎么「向开场动画看齐」

1. **先读终帧，再写卡片。** 每套主题在 `src/intro.css` 有一个开场区块，其最终
   静止态（动画播完的画面）就是设计基准。从中提取四样东西：
   **色板**（精确 hex，直接复用）、**母题**（至少 2 个签名母题进卡片）、
   **字体家族**（`--font-display` 系）、**材质**（渐变 / 噪点 SVG / 边线做法，
   data-URI 纹理可原样拷贝）。
2. **三种规格各自独立构图**，不是同一张换配色：
   - `poster` 1600×900：封面为主视觉，巨型时长数字；
   - `dossier` 1200×1500：画框封面 + 资料页（含 4 项事实 + 21 格阶梯）；
   - `score` 1600×840：封面板 + 数据面板（190px 大数字）。
3. **封面图永远是主角**（.sc-art 是玩家游戏的真实封面），开场母题做框架、
   装饰、材质与文字处理——卡片是「把玩家封面裱进主题的仪式里」，不是重画开场。
4. **DOM 不可改**。全部构图在 `themes/<id>/interfaces.css` 的 CARD CHARACTER 块
   （选择器一律 `html[data-theme="<id>"] .share-card …` 前缀）。

## 2. 硬规则（违反任何一条即返工）

1. 只改 `themes/<id>/interfaces.css` 的 CARD CHARACTER 块（整块替换）+
   `themes/<id>/theme.json` version patch +1（铁律 41）。**不碰** `src/share-cards.css`、
   HTML、其它主题、其它插槽。
2. 画布固定：poster 1600×900 / dossier 1200×1500 / score 1600×840；**任何元素不得
   溢出画布**（`node tools/share-shots.js --themes=<id>` 的 overflow 必须为 0）。
3. 对比度：小字 ≥4.5:1、大数字 ≥3:1（相对它的**真实底色**，含渐变底取最深端算）。
   禁止用 `opacity` 压字色（铁律 29）——需要次级就用实色混合。
4. 三个变体各自构图；封面图（.sc-art）必须保留且是视觉主角之一；品牌行、标题、
   时长、21 格阶梯、档位、签名行全部在场且可读。
5. 长标题安全：标题允许换行（共享层已有 `overflow-wrap:anywhere`），排版按两行
   标题预留余量；dossier 的 4 项事实文本超长用省略号（共享层已有）。
6. 卡片要经得起截图发出去：构图完成度高（背景材质铺满、边缘处理干净）、
   装饰不压文字（铁律 1）。
